# Pendência deliberadamente adiada

Alisson pediu em 07/10/2026 para aguardar a alteração de vendas de Oral Center Catalão.

O relatório atual consulta oportunidades ganhas do CRM. O dashboard de contas Clinicorp usa orçamentos aprovados e recebimentos elegíveis. Essas definições não são equivalentes.

Antes de implementar, decidir se o relatório deve reproduzir o dashboard ou separar vendas fechadas e recebimentos. Conferir também o mesmo período, origem e fuso. Não alterar a estrutura, dados ou código do Voxi; a integração do Painel é de leitura.

O editor, os períodos, campanhas e modo somente Meta podem evoluir independentemente. Não implementar a regra comercial adiada nessa entrega.
